# Jharkhandvasi Parivartan Sangh (JPS)
## Premium Nature-Inspired Social Welfare & Environmental Platform

Official digital home for **Jharkhandvasi Parivartan Sangh (झारखंडवासी परिवर्तन संघ)**, a grassroots social welfare non-governmental organization serving migrant workers, vulnerable elders, underprivileged children, and indigenous communities across Mumbai and Jharkhand.

---

## 🌿 Brand Identity & Design Direction

- **Palette:** Deep Forest Green (`#123B2A`), Evergreen (`#1D5139`), Moss Green (`#6F8D58`), Sage (`#B8CBA5`), Warm Ivory (`#F7F5EC`), Earth Brown (`#795943`), Charcoal (`#17231C`), and Amber Accent (`#E28723`).
- **Typography:** DM Serif Display / Editorial Serif paired with Plus Jakarta Sans.
- **Aesthetics:** Adapted from the spacious layouts, rounded cards (20–32px radius), refined editorial headlines, and subtle micro-interactions of modern digital leaders (Growth Nations inspiration), harmonized with the natural beauty and tribal heritage of Jharkhand.

## 🛠️ Advanced Technology Stack

- **Framework:** Next.js (App Router, Turbopack, React 19)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Custom Design System
- **Icons:** Lucide React (`lucide-react`)
- **Interactive Features:**
  - Responsive Sticky Navbar with Top 24/7 Helpline Strip
  - 4-Theme Animated Hero Slideshow with pause/play controls & progress indicators
  - Interactive Project Discovery Hub with verified location switchers
  - Documentary Photo Gallery with Keyboard-accessible Fullscreen Lightbox
  - Volunteer Application Form with field validation & reference IDs
  - Transparent Donation Impact Calculator & Verified Pledge Intent Flow
  - Searchable Resource Center with dynamic category filtering
  - Floating 24/7 Action Widgets (Direct WhatsApp & Phone Dialers)
  - Full SEO Meta Tags, Open Graph, Sitemap (`/sitemap.xml`) & Robots (`/robots.txt`)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
